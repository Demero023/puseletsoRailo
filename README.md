# Puseletso Railo

A personal, single-page website with a letter, a shared photo, and two embedded
YouTube videos. The page is built with plain HTML and CSS; it does not require a
build step or package installation.

## View the website

Open `index.html` in a web browser. The photo is stored locally in the project,
while the embedded YouTube videos require an internet connection.

## Project files

- `index.html` contains the page content and video embeds.
- `style/style.css` contains the page styling.
- `image/me-and-you.jpeg` is the photo displayed on the page.
